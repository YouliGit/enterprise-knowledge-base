本地部署

只需 Docker 与 Git，无需安装任何语言环境；首次构建约 5~15 分钟（已配置国内加速源）。

① 拉取并启动

# 克隆
git clone https://github.com/YouliGit/enterprise-knowledge-base.git
cd enterprise-knowledge-base

# 一键构建启动（4 容器）
docker compose up -d --build

# 可选：追加 Mock 大模型沙箱（零成本体验全链路）
docker compose --profile test up -d

② 访问系统

# 前端（管理端 + 智能问答门户）
http://localhost:8080

# 后端 API 文档（Swagger）
http://localhost:9090/docs

# 默认账号
admin / admin

# Mock 沙箱（启动 test profile 后）
模型地址填 http://mock-llm:8000，对话/向量带 /v1 前缀

────────────────────────────────────────────────────────
四、风险提示
────────────────────────────────────────────────────────
- 百炼 Key 未填时：登录、建库、传文档、检索测试等全部可用，
  仅「模型连通性测试 / 向量化入库 / 问答生成」会报 401/无key 错误。
  ※ 如需在无 Key 情况下演示全链路，可启动 Mock 沙箱：
    `docker compose --profile test up -d`（端口 8898），
    然后在管理端把三类模型的 api_base 指向 http://mock-llm:8000(/v1) 即可。
- 维度一致性：向量模型 text-embedding-v4 为 1024 维，
  settings.py EMBEDDING_DIM 与 pgvector_init.sql 中 vector(1024) 一致，
  若换其他维度向量模型，需同步改这两处并重建向量表。
- 已知技术陷阱（本轮踩坑后已修复，改造代码时注意，详见《项目进度.txt》末尾）：
  * Tortoise ORM + MySQL：bulk_create 不回填自增主键，需回查
  * asyncio 后台任务需保存强引用，否则被 GC 回收
  * 保存内容后要重新向量化，必须「先落库再 reembed」
  * HTTP/1.1 的 SSE 响应必须有 Transfer-Encoding: chunked

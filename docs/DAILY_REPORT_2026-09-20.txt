## ⏸ 当前状态

所有服务正常运行，下一步按文档三验证核心链路：
  1. 登录 http://localhost:8080（admin/admin）
  2. 进入管理端 → AI模型配置 → 添加对话/向量/重排模型
  3. 添加 Prompt 模板（可导入内置模板）
  4. 添加工具（可导入内置工具）
  5. 创建知识库 → 上传文档 → 等待解析完成
  6. 创建问答应用 → 绑定知识库/Prompt/模型/策略
  7. 进入用户端问答 → 选择应用 → 开始对话

⚠️ 注意：步骤 2 的模型配置需要百炼 API Key（付费项），
    未填写时检索/问答会报 401 错误，其他功能（建库/传文档/检索测试）正常可用。

◆ 2026-09-21 新增/修订的设计口径（改动需同步文档）：
  - 【重要】Tortoise ORM + MySQL：bulk_create 不回填自增主键（仅 PG 支持 RETURNING）。
    凡「批量插入后需要用主键建立关联」的场景，必须用 rag/ingest.py::_fetch_ids() 回查，
    不能依赖 c.id。
  - 【重要】asyncio 后台任务必须保存强引用（rag/ingest.py::_BG_TASKS），
    否则事件循环只持弱引用，任务会被 GC 中途回收（表现为文档永久 parsing）。
  - 【重要】保存内容后若要重新向量化，必须「先落库再 reembed」
    （reembed_chunk 以库中内容为准，否则会把内存改动覆盖掉）。
  - HTTP/1.1 响应必须有明确的 Content-Length 或 Transfer-Encoding: chunked，
    否则客户端永久挂起（mock-llm SSE 已改分块编码）。
  - rag/qa.py::stream_generate：有工具时前几轮非流式（拿 tool_calls），
    最终作答轮改 astream 逐 token 推送，保证前端仍是流式打字效果。
  - Agent 图的收敛控制用「图级 state["round"]」+ self_check_retry 显式标记，
    不能用 app_retrieve 的内部轮次（那个恒为 1）。
  - agent_step.seq 以「库中 max(seq)」为准递增（LangGraph 节点拿到 state 副本，
    内存计数会失效）。
  - 测试 SSE 必须用增量解码（codecs.getincrementaldecoder），逐字节 decode 会撕裂中文。
  - 测试轮询文档状态必须等「全部进入终态(parsed/failed)」，parsing 不算收敛。
